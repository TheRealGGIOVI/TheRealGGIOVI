## 🌟 Featured Project
### 🔹 [Navicom](https://github.com/TheRealGGIOVI/Navicom)  
An e-commerce platform for refurbished IT products, developed as my **Technical College Final Degree Project**.  
Navicom provides a complete online shopping experience with features like a persistent shopping cart, integrated payment gateway, and a comprehensive admin panel for managing products and users.
- **Backend:** C#, ASP.NET Core, Entity Framework, PostgreSQL
- **Frontend:** React, HTML, CSS
- **Infrastructure:** AWS (EC2, Nginx, CertBot), RESTful API, JWT Authentication
- **Key Features:** Stripe integration for payments, automated email notifications, scalable microservices architecture.
